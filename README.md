# OOP Calculator

A command-line calculator built in stages to practice object-oriented design.

## Setup

```bash
python3 -m venv .venv
source .venv/bin/activate
python -m pip install -r requirements.txt
```

## Run

```bash
python -m calculator
```

Commands: `add`, `subtract`, `history`, `remove`, `help`, `exit`.

## Test

```bash
python -m pytest
```

This runs all tests and requires 100% line and branch coverage.
